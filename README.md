## ➢ Sobre o Projeto

Este repositório reúne diversos mini-projetos e exercícios desenvolvidos com o objetivo de fortalecer a base em **desenvolvimento front-end**, focando na estruturação semântica de páginas e estilização moderna com CSS.

- Prática de conceitos fundamentais e avançados de layout (Flexbox e Grid)  
- Desenvolvimento de interfaces responsivas  
- Projetos baseados em cursos da **Alura** e tutoriais do **YouTube**
